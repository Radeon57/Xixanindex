# ⚔ God Killer — สังหารเทพ
|  ได้แรงบันดาลใจจาก [Idling to Rule the Gods](https://store.steampowered.com/app/466170/Idling_to_Rule_the_Gods/)  |



เกมไอเดิล (idle) ภาษาไทยบนเว็บ สร้างร่างเงา ฝึกกายและเวท ส่งไปสู้มอนสเตอร์ แล้วไต่ขึ้นไปท้าสังหารเทพทั้ง 10 องค์ 

> เกมนี้สร้างขึ้นใหม่ทั้งหมด ทั้งโค้ด ภาพ และเนื้อหา และไม่มีส่วนเกี่ยวข้องกับผู้พัฒนา *Idling to Rule the Gods*

### ▶ [เล่นเลย](https://radeon57.github.io/Xixanindex/)

เล่นในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง (หรือกด "เพิ่มลงหน้าจอหลัก" เพื่อติดตั้งเป็นแอปและเล่นแบบออฟไลน์ได้) ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ หน้าจอปรับตามขนาดเครื่องเอง

---

## วิธีเล่น
1. **ร่างเงา** จะถูกสร้างขึ้นเองทีละร่าง กด **+** เพื่อส่งไป **ฝึกกาย** (เพิ่มพลังโจมตี) หรือ **วิชาเวท** (เพิ่มพลังป้องกัน)
2. ส่งร่างเงาไป **สนามรบ** เพื่อหาพลังเทวะ (DP) ดูสีพลังศัตรูก่อนส่ง:
   - 🟢 เขียว: ปลอดภัย
   - 🟡 เหลือง: เสี่ยง
   - 🔴 แดง: ร่างเงาตาย
3. ไปที่แท็บ **ท้าเทพ** เมื่อคาดการณ์ขึ้นว่า "ชนะ" ให้กดท้าสู้ สังหารเทพแต่ละองค์จะปลดล็อกระบบใหม่
4. ติดเทพองค์ไหนนาน ให้ **เกิดใหม่** รับ God Power ไปซื้ออัปเกรดถาวร รอบต่อไปจะแข็งแกร่งขึ้นมาก
5. ระหว่างสู้เทพ กด **⚡ ฟาดฟันเทวะ** เพื่อโจมตีแรงพิเศษทุก 12 วินาที
6. ปิดเกมไปก็ยังได้ความคืบหน้า สูงสุด 8 ชั่วโมง กลับมาจะมีการ์ดสรุปให้ดู

## ระบบในเกม
| ระบบ | รายละเอียด |
|---|---|
| ฝึกกาย / วิชาเวท | อย่างละ 8 ขั้น ขั้นสูงได้พลังมากกว่า |
| สนามรบ | มอนสเตอร์ 10 ชนิด ให้ DP และค่ายุทธ์ |
| การสร้าง | สร้างสรรพสิ่ง 9 อย่างจากสูตรวัตถุดิบ ของทุกชิ้นให้โบนัส |
| ท้าเทพ | เทพ 10 องค์ และสิ่งมีชีวิตสูงสุดที่สู้ซ้ำได้ไม่จำกัด |
| เทวาลัย | เครื่องผลิตพลังเทวะ และอนุสรณ์ |
| เกิดใหม่ | God Power, อัปเกรดถาวร, ความท้าทาย 4 แบบ, แต้ม Might, ความสำเร็จ 20 อย่าง |
| คู่หู | สัตว์คู่หู 6 ตัว, ดันเจี้ยน 4 แห่ง, ตีบวกอุปกรณ์ |
| จัดอัตโนมัติ | ให้เกมจัดร่างเงาเองตามแผนที่เลือก |

## ปุ่มลัด (คอมพิวเตอร์)
| ปุ่ม | ทำอะไร |
|---|---|
| `1`–`8` | เปลี่ยนแท็บ |
| `F` / `Space` | ท้าสู้ / ถอยหนี (แท็บท้าเทพ) |
| `S` | ฟาดฟันเทวะ ระหว่างต่อสู้ |
| `H` | เปิดวิธีเล่น |
| `L` | เปิดบันทึกและเซฟ |
| `[` `]` | สลับหน้าย่อย |
| `Esc` | ยกเลิก / ปิด |
| `?` | ดูปุ่มลัดทั้งหมด |

## ย้ายเซฟไปเล่นเครื่องอื่น
เซฟเก็บในเบราว์เซอร์ของแต่ละเครื่อง ย้ายได้ 2 ขั้น:
1. เครื่องเดิม: เปิดบันทึก แล้วกด **คัดลอกโค้ด**
2. เครื่องใหม่: เปิดบันทึก วางโค้ดในช่อง แล้วกด **โหลดจากโค้ด**

## สำหรับนักพัฒนา
เกมเขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่มีขั้นตอน build และขึ้นเว็บผ่าน GitHub Pages เมื่อ merge เข้า `main`

```
god-killer.html        หน้าเกม + CSS ทั้งหมด
god-killer/data.js     ตัวเลขและชื่อทั้งหมด (ปรับสมดุลที่นี่)
god-killer/engine.js   กฎของเกม (ไม่แตะ DOM, รันใน Node ได้)
god-killer/ui.js       การแสดงผลและการควบคุม
god-killer/img/        ภาพตัวละคร 33 ภาพ (256×256 WebP)
tests/engine_fuzz.js   ทดสอบกฎของเกม
```

**รันบนเครื่อง:**
```bash
python3 -m http.server 8000
# เปิด http://localhost:8000/god-killer.html
node tests/engine_fuzz.js   # ทดสอบกฎของเกม (~5 วินาที)
```

ก่อนแก้โค้ด อ่าน **[AGENTS.md](AGENTS.md)** ในนั้นมีกติกาที่ห้ามทำพัง (เช่น เซฟเก่าต้องโหลดได้) และรายการงานที่ยังค้าง
